# W1D1 – NumPy Fundamentals

## Internship
Cynaris Solutions – Cybersecurity / AI-ML Internship

## Project Overview
This project demonstrates the fundamentals of NumPy, including array creation, array dimensions, broadcasting, vectorized operations, and matrix multiplication. It also uses a CSV dataset to calculate basic statistical values.

## Topics Covered
- Creating 1D, 2D, and 3D NumPy arrays
- Understanding array shape and dimensions
- NumPy broadcasting
- Vectorized arithmetic operations
- Matrix multiplication
- Calculating mean and standard deviation
- Finding correlation using NumPy
- Reading CSV data using Pandas
